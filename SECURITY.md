# Security Policy

Do not open public issues for vulnerabilities involving financial data, backups, PINs, keys, or local databases. Report privately to `sanskarin@outlook.in` with affected version, platform, reproduction steps, and impact. Never send real financial records, PINs, or backup passwords.

Finora uses integer minor units for money, SQLite transactions/WAL, OS secure storage for small secrets, and AES-GCM for exported backup confidentiality/integrity.
