# Release Checklist

- Verify package versions/licenses.
- Run formatting/static analysis.
- Build all target frameworks on appropriate hosts.
- Run unit, integration, migration, and UI automation suites.
- Smoke test onboarding, accounts, transactions, transfers, budgets, goals, recurrence, export, backup/restore, deletion, privacy mode, and app lock.
- Validate accessibility, large text, keyboard, screen reader, contrast, reduced motion.
- Verify no secrets/PII in artifacts/logs.
- Verify migrations from every prior schema.
- Keep signing credentials outside the repo.
- Update changelog/version/notices/store privacy disclosures.
